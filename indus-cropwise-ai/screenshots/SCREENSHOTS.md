## Real app screenshots to capture (for the NASA submission)
1. On your laptop, run the app: double-click `run.bat` (or `streamlit run app.py`).
2. When it opens at http://localhost:8501, capture each page with **Windows + Shift + S**
   (Snipping Tool), then save PNGs into this folder:
   - `01_home.png`
   - `02_farm_profile.png`
   - `03_nasa_climate_live.png`  (after pressing Fetch — badge should say LIVE NASA DATA)
   - `04_crop_catalogue.png`
   - `05_rotation_explorer.png`
   - `06_methodology.png`
3. Use these PNGs in your presentation / demo video.
