# AI Usage Disclosure — Indus CropWise AI
NASA Space Apps 2026 permits AI-assisted work with honest disclosure. This is ours.

## AI tools used
- **Claude (Anthropic)** — an AI coding assistant — was used by Team INDUSASTRA.

## Where AI assistance was used
- **Code drafting:** the Streamlit app, the NASA POWER service, the scoring/validation/rotation
  modules, the UI/CSS theme and the Plotly charts were drafted with AI assistance.
- **Debugging:** AI helped run the automated tests and a headless render of every page, identified
  two defects (duplicate Plotly chart IDs; a mixed-type table column) and fixed them.
- **Documentation:** this repository's README and markdown docs were drafted with AI assistance and
  reviewed by the team.
- **Synthetic sample data:** `data/demo_climate.csv` was **generated by AI** as an offline fallback.
  It is clearly labelled as `SAMPLE_SYNTHETIC` in every row and in `data/demo_climate_meta.json`, and
  the app shows a red "SAMPLE DATA (NOT NASA)" badge whenever it is used.

## What AI did NOT do
- AI did **not** generate, verify, validate or alter any genuine NASA POWER observation data. Live NASA
  data is fetched directly from the NASA POWER API at run time and displayed as received.
- AI did **not** invent agricultural facts or references; crop information is based on general FAO/agronomy
  references listed in `DATA_SOURCES.md`.
- The rule-based scoring is **not** an AI/ML model — it is explicit, human-readable arithmetic.

## Generated media / watermarking
- The application uses **CSS, original styling, standard emoji icons and code-generated Plotly charts**
  only. No AI-generated photographs, illustrations or videos are used in the app, so no image/video
  watermark is required for the application itself.
- If AI-generated images or video are later added to the final presentation or demo video, they will
  carry a visible "AI-generated" watermark as the NASA guide requires.

## Honesty statement
All data-source, "live vs sample", and capability claims in this project are intended to be accurate.
Where the tool lacks information or certainty, it says so.
